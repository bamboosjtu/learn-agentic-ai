# 使用 OpenAI Canvas

[OpenAI Canvas 挑战 Google Docs、VS Code 和 Cursor](https://analyticsindiamag.com/ai-origins-evolution/openai-canvas-kills-google-docs-challenges-vs-code-cursor/)

 ChatGPT Canvas 正式上线，它把 ChatGPT 从“聊天助手”扩展成了一个更像协作文档和代码工作台的工具。

- **Canvas 是什么**
  - 它是 ChatGPT 的一个“可编辑工作区/画布”，你可以把文本或代码放进去，和 AI 一起修改、润色、调试，而不是只靠来回对话。
  - 文章把它类比为“文案编辑器”或“代码审阅者”。

- **它能做什么**
  - 用户可以高亮某一段内容，让 ChatGPT只关注那一部分。
  - 支持直接在画布里编辑文本和代码。
  - 提供快捷操作，比如调整文章长短、调试代码、执行其他常见修改。
  - 还能恢复之前的版本，方便回退。

- **怎么使用**
  - 可以在提示词里输入 `use Canvas`。
  - 也可能在 ChatGPT 判断“这个任务适合画布模式”时自动弹出。

- **这次正式发布带来的更新**
  - 文章说，Canvas 已不再只是 Plus/Team 的 Beta 功能，而是面向所有 ChatGPT 用户开放。
  - 对程序员的增强包括：可以编辑和翻译成 Python 代码，并且新增 `Run` 选项，能直接运行代码看结果。
  - 还可以把 Canvas 嵌入到 Custom GPT 里，做成更定制化的协作工具。
