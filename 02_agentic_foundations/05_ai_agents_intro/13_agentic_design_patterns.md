# Agentic 设计模式

[Design Patterns](https://www.linkedin.com/posts/rakeshgohel01_not-all-ai-agents-are-created-equally-here-activity-7276242517904302080-gsTJ?utm_source=share&utm_medium=member_desktop)

Agentic Design Patterns 指的是在构建自治 AI Agent 时反复出现的一类解决方案或组织方式。这些模式定义了 Agent 如何推理、如何行动，以及如何与环境、其他 Agent 或用户互动以达成目标。它们本质上是一组概念框架，用来指导 AI Agent 的设计与实现，从而在复杂动态环境中最大化效率、适应性和整体表现。

“agentic” 这个词强调的是系统的自主性，也就是它们可以在不依赖持续人工干预的情况下，独立运行、做决策并执行动作。

下面是一些常见的 **Agentic AI 设计模式**：

### 1. **ReACT（Reasoning and Acting）**
- **概述**：把推理与行动放在一个循环中交替进行。
- **例子**：旅行规划 Agent 边研究航班边执行预订。
- **优势**：适合需要顺序决策和中间反馈的任务。
- **劣势**：如果推理不收敛，可能陷入循环。

### 2. **自我改进（Self-Improvement）**
- **概述**：Agent 持续评估并优化自身能力。
- **例子**：编码助手根据用户反馈和新数据不断改进。
- **优势**：适应新挑战并持续变强。
- **劣势**：需要算力和严格监控。

### 3. **Agentic RAG**
- **概述**：把检索系统与生成式 AI 结合。
- **例子**：客服 Agent 检索政策文档后生成个性化答复。
- **优势**：让生成结果建立在外部事实基础之上。
- **劣势**：依赖检索质量。

### 4. **Meta-Agent**
- **概述**：上层 Agent 管理多个专门化子 Agent。
- **例子**：项目经理 AI 协调排程、预算和报告 Agent。
- **优势**：可扩展、模块化。
- **劣势**：协调难度高。

### 5. **Planner-Executor**
- **概述**：把规划与执行分成两个角色。
- **例子**：游戏 AI 先规划，再执行。
- **优势**：职责清晰。
- **劣势**：如果环境频繁变化，重规划成本高。

### 6. **反射型 Agent（Reflexive Agent）**
- **概述**：基于刺激 - 响应快速反应。
- **例子**：扫地机器人碰到障碍立刻转向。
- **优势**：适合实时任务。
- **劣势**：面对复杂情况适应性差。

### 7. **交互式学习（Interactive Learning）**
- **概述**：通过用户反馈不断调整行为。
- **例子**：语言模型根据用户纠正改进回复。
- **优势**：更贴近用户真实需求。
- **劣势**：依赖反馈质量。

### 8. **分层任务分解（Hierarchical Task Decomposition）**
- **概述**：把复杂任务拆成更小子任务。
- **例子**：组织活动时拆成订场地、发邀请、排日程。
- **优势**：适合复杂多步骤任务。
- **劣势**：依赖准确的任务拆分。

### 9. **目标导向 Agent（Goal-Oriented Agent）**
- **概述**：围绕目标设定、追踪和修正来行动。
- **例子**：理财 Agent 根据储蓄目标调整投资策略。
- **优势**：行为聚焦。
- **劣势**：面对冲突目标容易出问题。

### 10. **上下文记忆（Contextual Memory）**
- **概述**：利用记忆增强未来决策和回答。
- **例子**：对话 Agent 跨会话记住用户偏好。
- **优势**：提升连续性和个性化。
- **劣势**：需要良好的数据管理。

### 11. **协作式多 Agent 系统（Collaborative Multi-Agent Systems）**
- **概述**：多个 Agent 共同协作完成共享目标。
- **例子**：无人机协同在城市中配送包裹。
- **优势**：任务可分布式并行完成。
- **劣势**：需要强通信和冲突解决能力。

### 12. **探索型 Agent（Exploratory Agent）**
- **概述**：重点在探索未知环境或数据。
- **例子**：研究助手 AI 扫描期刊寻找趋势。
- **优势**：适合发现新机会。
- **劣势**：可能浪费资源在无关探索上。

### 13. **自适应工作流编排（Adaptive Workflow Orchestration）**
- **概述**：根据环境和资源变化动态调整工作流。
- **例子**：医院运营 AI 根据病人涌入重新分配资源。
- **优势**：灵活应变。
- **劣势**：算力消耗大。

### 14. **自愈系统（Self-Healing Systems）**
- **概述**：系统能发现并修复自身故障。
- **例子**：云管理 Agent 自动修复故障节点。
- **优势**：提高可靠性。
- **劣势**：实现与调试复杂。

### 15. **伦理决策（Ethical Decision-Making）**
- **概述**：在决策中显式纳入伦理考量。
- **例子**：自动驾驶车辆根据伦理原则处理风险选择。
- **优势**：让 AI 更符合社会价值。
- **劣势**：伦理标准本身可能存在歧义。
