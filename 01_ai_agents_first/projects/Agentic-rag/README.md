# Agentic RAG 聊天机器人

## 什么是 LLM？

大语言模型（LLM）是一类在海量文本数据上训练出来的高级人工智能模型。像 OpenAI GPT 系列这样的 LLM，能够理解并生成人类语言，因此在聊天机器人、内容生成、摘要、问答等各种自然语言处理任务中都非常强大。

## 什么是 RAG（检索增强生成）？

RAG（Retrieval-Augmented Generation）是一种把 LLM 的生成能力与信息检索系统结合起来的技术。在 RAG 系统中，模型会先从数据库或外部知识源中检索相关文档，再利用这些信息生成更准确、更有上下文、且更贴近最新事实的回答。它能弥补 LLM 无法天然掌握最新信息或领域专有知识的问题。

## 什么是 Agentic RAG？

Agentic RAG 在传统 RAG 的基础上进一步引入 Agent 化行为和工作流。在 Agentic RAG 中，自主 Agent 可以进行推理、规划，并和多个工具或数据源交互，来检索、综合并呈现信息。这使得聊天机器人更加动态，能够处理更复杂的问题，并编排多步骤任务。

## 为什么 Agentic RAG 对聊天机器人很重要？

- **更高准确性：** 通过实时检索相关信息，聊天机器人可以给出更精确、更新鲜的回答。
- **上下文感知：** Agentic RAG 让聊天机器人能理解并利用多个来源中的上下文，提升交互质量。
- **复杂任务处理：** Agent 化系统可以拆解并解决多步骤问题，让聊天机器人适用于更高级的场景。
- **可扩展性：** Agent 系统是模块化的，因此很容易接入新的工具和数据源。

## 项目描述

这个项目的目标是构建一个 Agentic RAG 聊天机器人，它能够根据从特定网站抓取到的信息回答问题。整体过程包括以下几个关键步骤：

1. **网页抓取**
   自动从目标网站提取相关内容，例如文章、FAQ、文档或其他有用文本数据。
2. **将数据存入向量数据库**
   对抓取到的数据进行处理，并存储到向量数据库中，以支持高效的语义搜索与检索。
3. **与 LLM 集成**
   把向量数据库连接到大语言模型。当用户提问时，系统会从数据库中检索最相关的信息，并把它作为上下文提供给 LLM，从而生成更准确、更具上下文的回答。
4. **运行聊天机器人**
   部署一个用户可交互的聊天界面。聊天机器人通过 Agentic RAG 方式，结合“检索 + 生成”能力，给出动态、最新且上下文丰富的回答。

通过完成这个项目，你将得到一个真正可用的聊天机器人，它能够基于你选定网站中的最新信息进行问答，从而展示 Agentic RAG 系统在真实应用中的价值。

## 第一步：配置 Python 环境

1. **安装最新版本的 Python**
   - 从 [Python 官网](https://www.python.org/downloads/) 下载并安装最新版 Python
   - 通过以下命令确认安装成功：
     ```bash
     python --version
     ```
     或
     ```bash
     python3 --version
     ```

2. **安装 UV（Universal Virtualenv & Package Manager）**
   - UV 是一个快速的 Python 包管理与环境工具，可以通过 pip 安装：
     ```bash
     pip install uv
     ```
     如果你安装了 pipx，也可以：
     ```bash
     pipx install uv
     ```
   - 使用以下命令验证安装：
     ```bash
     uv --version
     ```

3. **使用 UV 创建新项目**
   - 初始化一个新的 Python 打包项目（把 `agentic_rag_chatbot` 替换成你自己的项目名）：
     ```bash
     uv init --package agentic_rag_chatbot
     ```
   - 该命令会创建一个新项目目录，并自动生成包管理和开发所需的基础文件。
