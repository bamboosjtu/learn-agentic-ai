# Swarm

OpenAI 的 Swarm 是一个实验性框架，旨在以轻量且易用的方式编排多智能体系统。它引入了两个核心抽象：**Agents（智能体）** 和 **handoffs（交接）**。其中，智能体封装了特定指令与工具；交接机制允许智能体之间转移控制权。这种设计使多个专注于不同任务的 AI 智能体能够实现可扩展、可测试的协作，从而共同完成复杂目标。

在近期发展中，OpenAI 发布了 **Agents SDK**，这是 Swarm 框架面向生产环境的演进版本。Agents SDK 构建在 Swarm 首次提出的基础概念之上，并提供了更完善的多智能体工作流编排能力。这一进展让开发者可以更高效地管理和协调复杂任务，确保不同智能体围绕统一目标协同工作。

因此，最近发布的 OpenAI Agents SDK 的确建立在 Swarm 框架最初探索的设计模式与原则之上，标志着多智能体 AI 系统向更成熟、更一体化方向迈出的重要一步。

**Agents（智能体）** 是具备特定指令与工具的自治实体，用于执行指定任务。每个智能体独立运行并专注自身角色，从而提升系统中的专业化程度与执行效率。比如在客服应用中，可由不同智能体分别处理账单咨询、技术支持和通用信息请求。

**Handoffs（交接）** 是指在智能体之间转移控制权与上下文的机制。这使系统能够依据当前上下文或用户请求，将任务动态路由到最合适的智能体。例如，当通用咨询智能体识别到问题与账单有关时，它可以把对话交接给账单智能体，确保用户问题由最匹配的实体处理。


Swarm 框架强调极简思路，重点在于简单性与灵活性。这种设计使开发者能够在不引入大型框架复杂度的前提下，快速开展多智能体编排实验。借助这些核心抽象，Swarm 可以构建可扩展、可测试且高效的多智能体系统，以处理复杂的协作型任务。


## Anthropic 设计模式

OpenAI 的 Agents SDK 是一个通用框架，旨在支持 AI 智能体的开发与编排，使其能够高效执行复杂任务。该 SDK 与 Anthropic 提出的多种智能体设计模式高度契合，开发者可据此顺畅落地这些模式。

https://www.anthropic.com/engineering/building-effective-agents

**1. Prompt Chaining（链式工作流）：**

该模式将复杂任务拆分为一系列更简单、可管理的步骤，并让后续步骤建立在前一步结果之上。Agents SDK 通过允许开发者定义按既定顺序执行特定功能的智能体来支持该模式，从而为任务完成提供结构化路径。

**2. Routing（路由）：**

路由是指根据任务性质把任务分配给最合适的智能体。Agents SDK 通过其 handoff 机制支持这一点，使智能体可将控制权转交给更适合处理某个子任务的其他智能体，从而优化任务管理。

**3. Parallelization（并行化）：**

该模式强调并发执行多个子任务以提升效率。借助 Agents SDK，开发者可以设计并行运行的智能体，并利用 SDK 的编排能力高效管理并发流程。

**4. Orchestrator-Workers（编排者-执行者）：**

在该设计中，编排智能体会将复杂任务拆分为更小的子任务，并分配给执行智能体。Agents SDK 的架构支持这一模式：编排智能体可统筹整体流程，并把任务委派给专业执行智能体，确保协同执行。

**5. Evaluator-Optimizer（评估者-优化者）：**

该模式通过反馈闭环实现迭代改进：评估智能体评估其他智能体表现并提出优化建议。Agents SDK 的 guardrails（护栏）能力可用于实现这类评估机制，从而持续提升性能并确保行为符合预期。

通过使用 OpenAI Agents SDK，开发者可以有效实现 Anthropic 提出的这些设计模式，构建稳健且高效的 AI 智能体系统。
