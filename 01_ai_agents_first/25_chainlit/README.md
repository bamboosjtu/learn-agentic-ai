# 使用 Chainlit 构建对话式 AI

[官方文档](https://docs.chainlit.io/get-started/overview)

运行完 `helloworld` 之后，再回头阅读文档。

Chainlit 是一个**开源 Python 框架**，专门用来让你可以直接用 Python 快速构建**对话式 AI 应用**。你可以把它理解为一个能够快速生成聊天界面的工具，适合用来做聊天机器人、AI 助手，以及各种由大语言模型（LLM）驱动的应用。

下面是对 Chainlit 及其核心特点的说明：

**核心目标：**

* **简化对话式 AI 的 UI 开发**：Chainlit 的主要目标，是在复杂 AI 模型（尤其是 LLM）和用户友好的界面之间搭起桥梁。传统做法通常需要大量前端开发，而 Chainlit 让你把重点放在 Python 后端逻辑上，把 UI 交给框架处理。
* **快速原型与开发**：它强调开发效率。你可以快速迭代自己的对话式 AI 想法、进行测试，并交付给用户，而不需要自己是前端专家。
* **专注对话流程**：Chainlit 是专门为对话交互设计的，提供了适合多轮对话的能力和 UI 组件，比如显示消息、管理输入、处理会话轮次等。

**主要特性与能力：**

* **Python 优先**：所有事情都在 Python 中完成。你可以直接用 Python 编写应用逻辑、UI 元素和对话流程。这对基于 Python 开发 AI 应用的人非常友好。
* **实时通信**：Chainlit 应用支持实时交互。用户可以即时发送消息并获得回复，形成顺畅的对话体验。
* **丰富的 UI 元素**：它不仅支持简单的文本输入输出，还提供更多 UI 能力，包括：
    * **文本**：显示用户和机器人消息
    * **图片**：在对话中展示图片
    * **音频与视频**：嵌入音视频内容
    * **文件**：处理文件上传和下载
    * **按钮与动作**：供用户点击的交互按钮和操作
    * **表单**：创建结构化输入表单
    * **图表与可视化**：展示数据图表
* **异步支持**：基于异步 Python（`asyncio`）构建，适合处理并发用户交互和可能耗时较长的模型计算。
* **状态管理**：提供会话状态管理机制，可以在多轮对话之间保留上下文和用户偏好。
* **中间件与钩子**：支持中间件和 hooks，可以在对话流程的不同阶段加入自定义逻辑，例如认证、日志记录等。
* **易于部署**：Chainlit 应用易于部署。你可以在本地运行，也可以部署到云平台。
* **开源与社区驱动**：作为开源项目，它受益于社区贡献、持续迭代和透明性。

**可以这样理解它：**

如果说 Streamlit 或 Gradio 很适合快速构建通用型数据科学和机器学习界面，那么 **Chainlit 则是专门为对话式 AI 定制的**。你可以把它理解成“面向聊天机器人场景优化过的 Streamlit”，重点放在对话流程和丰富消息类型上。

**适合谁使用？**

* **AI/ML 工程师和开发者**：那些在构建聊天机器人、AI 助手和 LLM 驱动应用，并希望快速做出可用界面的人
* **数据科学家**：用于原型验证和展示对话式 AI 模型
* **任何希望快速实验并部署对话式 AI 点子的人**
* **教育者与研究人员**：用于教学和探索对话式 AI 概念

**总结：**

Chainlit 是一个功能强大且易用的 Python 框架，显著简化了对话式 AI 应用交互界面的构建过程。它让你能够在 Python 生态中快速构建、测试和部署带有丰富功能的聊天机器人与 AI 助手。如果你正在做任何与对话式 AI 相关的项目，Chainlit 很值得深入了解。



## 安装

    uv add openai-agents python-dotenv chainlit

运行项目时使用以下命令：

    cd chatbot
    
    uv venv

在 Mac 上：

    source .venv/bin/activate

使用 uv 运行项目：

    uv run chainlit run main.py -w
